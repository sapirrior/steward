## 1. PROJECT OVERVIEW & BOUNDARIES

- **Steward** is an interactive AI engineering terminal assistant built with TypeScript running natively on Bun.
- **`packages/tui` (`stitchable`)** is the custom alternate-screen terminal UI engine built with zero external dependencies (except `string-width`). It uses Mode 2026 Synchronized Output (`\x1b[?2026h` ... `\x1b[?2026l`), line-differential character rendering, and a stitched scrollback history architecture.
- **Strict Package Boundary Rule:** All changes for this engine audit are strictly confined to `packages/tui/`. Never edit files in `.agents/` or outside `packages/tui/`.

## 3. THE INPUT LISTENER ISSUE & ROOT CAUSE ANALYSIS

### Symptom:
When running the interactive CLI, typing any key caused `[` to be inserted into the prompt.

### Root Cause:
1. In `TerminalEngine.ts`, `addInputListener` was updated to pass parsed event objects (`ev: InputEvent` = `{ type: 'key', input: 'a', key: {...} }`) instead of raw string chunks (`str: string`).
2. Components in `packages/cli` (e.g. `PromptInput.tsx`, `TrustGate.tsx`, `app.ts`, `select-list.ts`) register listeners using `engine.addInputListener((chunk) => ...)` and perform string normalization:
   ```ts
   const rawStr = typeof chunk === 'string' ? chunk : String(chunk);
   const events = parseInputChunk(rawStr);
   ```
3. Because `chunk` was an object, `String(chunk)` produced `"[object Object]"`.
4. `parseInputChunk("[object Object]")` parsed the first character `'['`, causing every key press to be interpreted as `'['`.

### Resolution Required in `packages/tui`:
1. In `packages/tui/src/engine/TerminalEngine.ts`:
   - `addInputListener` must support a dual-contract signature:
     ```ts
     addInputListener(listener: (chunk: string, event: TerminalEvent) => boolean | void): () => void
     ```
   - When dispatching, `TerminalEngine` must pass the clean string `str` as the first argument and the structured `TerminalEvent` as the second argument.
   - Also ensure `scrollUp(amount = 1)` and `scrollDown(amount = 1)` helper aliases exist on `TerminalEngine`.
2. In `packages/tui/src/terminal/input.ts`:
   - `parseInputChunk(chunk: string | Buffer | InputEvent | TerminalEvent): InputEvent[]` should handle strings, Buffers, or structured event objects seamlessly.
3. In `packages/tui/src/runtime/mount.ts`:
   - `mount.ts` listener should handle `ev` (or `parseInputChunk(chunk)`).
